Ciptakan gayamu sendiri dengan jersey, sepatu, dan tampilan yang mencolok menggunakan teknologi motion capture terbaru dari pemain bintang sungguhan, lalu bawa gaya favoritmu ke lapangan.

FAQ

Apakah Soccer Superstar gratis?

Ya — Soccer Superstar sepenuhnya gratis diunduh dan dimainkan di iOS maupun Android. Game ini didukung oleh pembelian dalam aplikasi opsional dan iklan.

Bisakah saya main tanpa koneksi internet?

Tentu saja. Soccer Superstar dirancang untuk dimainkan offline — termasuk mode Liga, Turnamen, dan Latihan. Cukup unduh sekali dan nikmati kapan saja, di mana saja.

Tersedia di perangkat apa saja?

Soccer Superstar tersedia di Android (Google Play), iOS (App Store), dan tablet Amazon Fire (Amazon Appstore). Game ini berating Semua Umur, sehingga cocok untuk pemain segala usia.

Bagaimana cara kerja kontrolnya?

Mekaniknya sederhana: usap untuk menendang — cukup usap jarimu di atas bola untuk menembak. Arah, kecepatan, dan lengkungan usapanmu menentukan lintasan bola. Tanpa tombol, tanpa joystick.

Bagaimana cara membuka pemain baru?

Mainkan level utama untuk mendapatkan paket hadiah dan mengumpulkan pecahan pemain. Setelah pecahan seorang pemain terkumpul cukup, dia bisa kamu masukkan ke skuad.

Apa itu Tantangan Harian?

Tantangan Harian adalah event terbatas yang hadir secara berkala — kira-kira sebulan sekali. Setiap event punya stadion bertema dan perlengkapan eksklusif, sehingga seluruh pengalamannya sesuai dengan suasana event. Selesaikan sebelum waktunya habis untuk mengklaim hadiahnya.
